# AI 안경

AI 안경을 쓰고 감독관 눈을 피해 시험을 치는 1인칭 3D 게임 프로토타입이에요. 대학 중간고사에서 시작해 토익, 한국사, 수능, 9급 공무원, LEET, 세무사 2차를 거쳐 변호사시험까지 가요.

**▶ 플레이: https://mannolmeok.github.io/ai-glasses/**

## 조작

| | 휴대폰 (가로로 들기) | PC |
|---|---|---|
| 고개 돌려 감독관 보기 | 화면 왼쪽·오른쪽 꾹 | ← → |
| AI 스캔 | 화면 가운데 꾹 | Space |
| 답 마킹 | 보기 누르기 | 1~4 |
| 일시정지 · 소리 | | P · M |

진행 상황은 플레이한 브라우저에만 저장돼요. 제목 화면 왼쪽 아래 숫자가 지금 버전이에요.

## 만든 방식

AI(Claude)와 함께 만든 프로토타입이에요. 3D는 [three.js](https://threejs.org) 0.186.1(MIT 라이선스)을 `vendor/three.js`로 넣어 써요.
